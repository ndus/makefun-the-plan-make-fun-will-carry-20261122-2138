This program writes the fixed 30-day plan to `<output>/entry.txt`, using `MAKEFUN_OUTPUT_DIR` or `/output`.
It starts with small, escrowed PDF-to-Shopify CSV jobs and compounds weekly revenue through repetition, referrals, and reinvestment.
The three-row sample makes the first pitch concrete and low-risk for buyers.
The plan is intentionally short, measurable, and executable in public.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
